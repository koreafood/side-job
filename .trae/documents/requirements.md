## 목표
핸드메이드 상품을 판매하는 마켓플레이스의 핵심 구매 흐름을 구현한다.

## 사용자 역할
- 방문자(비로그인): 상품/판매자 조회, 장바구니 담기, 리뷰 조회
- 구매자(간단 인증 없이 데모): 리뷰 등록, 주문 생성
- 관리자(데모 범위): 별도 화면/권한은 본 구현 범위에서 제외(추후 확장)

## 핵심 기능(스크린샷 기준)
### 판매자 프로필
- 판매자 프로필 조회(이름, 소개, 대표 이미지)
- 판매자 최신 상품 1개(또는 목록) 미리보기 카드

### 상품 상세
- 상품 상세 조회(이름, 가격, 판매자, 설명)
- 이미지 갤러리(대표 이미지 + 썸네일)
- 장바구니 담기

### 구매자 리뷰
- 상품별 리뷰 목록 표시
- 리뷰 등록(닉네임, 평점, 본문)

### 장바구니 흐름
- 장바구니에 담긴 상품 목록 표시
- 수량 변경/삭제
- 주문 생성(데모: 배송/결제는 생략, 주문 데이터만 생성)

## 비기능 요구사항
- 프론트: Vue 3 + TypeScript + Vite + Tailwind, SPA
- 백엔드: FastAPI + SQLite, REST API
- CORS 허용(로컬 개발)
- 데모 데이터를 자동 시드(seed)하여 초기 화면이 바로 보이도록 구성
