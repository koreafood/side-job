# 관리자 주문 관리 화면 - Page Design

## 공통(관리자 레이아웃)
- Layout: Desktop-first 기준 **CSS Grid**(좌측 사이드바 240px + 우측 콘텐츠 1fr). 상단은 페이지 헤더(고정), 콘텐츠는 세로 스크롤.
- Breakpoints: 
  - ≥1200px: 사이드바 고정 노출
  - 768~1199px: 사이드바 아이콘 축소(72px), 텍스트는 툴팁
  - <768px: 사이드바 드로어로 전환(필수는 아니나 추후 확장 가능)
- Global Styles(토큰 예시):
  - Background: #F7F8FA, Surface: #FFFFFF, Border: #E5E7EB
  - Primary: #2563EB, Danger: #DC2626, Success: #16A34A
  - Typography: 12/14/16/20/24 scale, 본문 14px
  - Button: primary/secondary/ghost, hover 시 밝기 +4%, disabled 40% opacity
  - Table: 헤더 고정(선택), zebra row(아주 약하게)

1. 로그인 카드

   - 버튼: "로그인"
   - 상태: 로딩(스피너), 오류(상단 인라인 알림)
2. 보안/안내
   - "권한이 없는 계정은 접근할 수 없습니다" 안내 문구

## 2) 주문 목록 (/admin/orders)
### Meta Information
- title: "주문 목록"
- description: "주문을 검색, 필터링하고 상세로 이동"
- og:title: "주문 목록"

### Page Structure
- 상단: 페이지 타이틀 + (선택) 요약 배지(예: 전체/진행중)
- 그 아래: **필터 바** → **테이블** → **페이지네이션** 순으로 스택.

### Sections & Components
1. Page Header
   - 타이틀 "주문 목록"
   - (선택) 현재 적용된 필터 요약 chips(해제 가능)
2. 검색/필터 바(1~2줄)
   - 키워드 입력(placeholder: "주문번호/이름/연락처") + 검색 버튼
   - 기간 필터: 시작일~종료일(date range)
   - 상태 필터(드롭다운): 주문상태, 결제상태, 배송상태
   - 버튼: "초기화"(모든 조건 해제)
3. 주문 테이블
   - 컬럼(필수): 주문번호, 주문일시, 주문자, 총액, 주문상태, 결제상태, 배송상태, 액션
   - 행 클릭 또는 "상세" 버튼으로 상세 페이지 이동
   - 정렬: 주문일시 기본 desc, 컬럼 헤더 클릭으로 변경
   - 빈 상태: "조건에 맞는 주문이 없습니다" + 초기화 안내
4. 페이지네이션
   - 이전/다음, 페이지 번호, 페이지 크기(예: 20/50/100)

Interaction/States
- 필터 변경 시: "적용" 즉시 반영(또는 Enter/검색 버튼 시 반영 중 한 방식 선택)
- 로딩: 테이블 스켈레톤
- 에러: 상단 토스트 + 재시도

## 3) 주문 상세 (/admin/orders/:orderId)
### Meta Information
- title: "주문 상세"
- description: "주문 정보 확인 및 상태 변경"
- og:title: "주문 상세"

### Page Structure
- 2단 그리드(Desktop): 좌측(요약/고객/배송/결제), 우측(상태 변경/이력). 하단에 상품 리스트.
  - Grid 예: 상단 2열(7:5) + 하단 full width.

### Sections & Components
1. 상단 바
   - "목록으로" 버튼
   - 주문번호/주문일시 헤더
2. 주문 요약 카드
   - 총액, 주문상태/결제상태/배송상태 배지(색상으로 구분)
3. 고객/배송 정보 카드
   - 주문자/수령자(이름, 연락처)
   - 배송지(주소1/주소2), 배송 메모
4. 상태 변경 패널(우측 상단)
   - 현재 상태 표시
   - 다음 상태 선택(드롭다운)
   - (선택) 변경 사유 입력(짧은 텍스트)
   - 저장 버튼
   - 검증/오류: 전이 불가/권한 없음/네트워크 오류 메시지 구분
5. 변경 이력(우측 하단)
   - 테이블: 변경일시, 변경자, 이전상태 → 다음상태, 사유
6. 상품 라인아이템(하단)
   - 테이블: 상품명, 옵션, 수량, 단가, 소계

Interaction/States
- 저장 성공: 배지/이력 즉시 갱신 + 토스트 "상태가 변경되었습니다"
- 동시 수정 방지(권장): 저장 시 최신 상태 재확인(서버 원자 처리 기준)
