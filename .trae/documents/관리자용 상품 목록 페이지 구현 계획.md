## 페이지 개요
- 경로: /admin/products (requiresAdmin)
- 컴포넌트: AdminProductsPage.vue
- 목적: 관리자에게 상품 전체 목록을 테이블로 제공하고 전시여부 필터 및 수정 페이지 이동을 지원

## 표시 항목 및 레이아웃
1. 상단 필터 바
- 셀렉트: 전시여부 필터(전체/전시중/전시중지)
- (선택) 검색어 입력과 새로고침 버튼

2. 테이블 본문
- 열: 썸네일(50x50), 상품코드(id), 상품명, 가격(3자리 쉼표), 전시여부(전시중/전시중지)
- 썸네일 로딩 실패 시 기본 이미지(https://placehold.co/50x50?text=IMG)로 대체
- 상품코드는 파란색 링크로 표시, 클릭 시 수정 페이지로 이동
- 수정 페이지 링크: /admin/product/{상품코드}/edit (라우터에 alias 경로 추가하여 기존 /admin/products/:productId/edit와 병행 지원)

## 기능 요구사항 구현
- 전시여부 필터: 셀렉트 변경 시 목록 재요청
- 라우팅: 상품코드 링크 → /admin/product/{상품코드}/edit
- 가격 표기: Intl.NumberFormat('ko-KR') 사용

## 백엔드 API 추가
- GET /api/admin/products
  - 쿼리: published=all|true|false, q(optional), page(optional, 기본 1), pageSize(optional, 기본 20)
  - 응답: { items: Array<{ id, name, priceJpy, published, images: [{url, sort}] }>, total, page, pageSize }
  - 구현 포인트: 공개/비공개 모두 조회, images는 sort asc로 첫 번째를 썸네일로 사용

## 프론트엔드 API 클라이언트 추가
- api.listAdminProducts(params: { published?: 'all'|'true'|'false'; q?: string; page?: number; pageSize?: number })
- 응답 그대로 사용하여 테이블 렌더링

## 라우터 수정
- /admin/products 라우트 추가 (AdminProductsPage.vue)
- /admin/product/:productId/edit 라우트 alias 추가 → 기존 AdminProductEditPage.vue 컴포넌트 재사용

## 컴포넌트 구현 요약(AdminProductsPage.vue)
- 상태: items[], total, page, pageSize, filterPublished('all'|'true'|'false'), loading, error
- onMounted: listAdminProducts 호출, 필터 변경 시 재호출
- 템플릿: 상단 필터 + 테이블(요구 항목 정확히 반영)
- 썸네일: :src="thumbUrl" @error="e.target.src = fallbackUrl"

## 데이터/URL 처리 주의사항
- 서버가 이미지 URL을 절대 경로로 반환(이미 구현됨) → 그대로 img src 사용
- 비공개 상품은 공개 GET /api/products/:id로 조회 시 404가 정상 동작, 관리자 목록 API로만 조회

## 커밋 메시지(예정)
- feat(admin): 관리자용 상품 목록 페이지 구현 및 전시여부 필터 추가
- feat(api): GET /api/admin/products 엔드포인트 추가
- feat(router): /admin/products 라우트 및 /admin/product/:id/edit alias 추가
- feat(front): api.listAdminProducts 메서드 추가, 가격/썸네일 표시 로직 구현
