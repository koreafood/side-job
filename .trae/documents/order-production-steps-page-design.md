# 페이지 설계: 주문 상세 제작 단계 + 고객 조회

## 공통(전역) 설계
### Layout
- 데스크톱 우선: 기본 1200px 컨테이너 + 좌우 패딩 24px.
- 주문 상세는 상단 요약 + 아래 타임라인(세로 스택). 사진은 그리드/캐러셀 하이브리드.
- 반응형: 1024px 이하에서 사진 그리드는 2열, 640px 이하에서는 1열 및 타임라인을 카드 리스트 형태로 단순화.

### Meta Information
- Title: `주문 상세 | {orderId}`
- Description: `주문 제작 진행 상황과 단계별 사진을 확인합니다.`
- Open Graph: `og:title`, `og:description`, `og:type=website`

### Global Styles
- Background: `#F7F8FA`
- Surface(Card): `#FFFFFF`, Border: `#E5E7EB`
- Primary: `#2563EB` (버튼/링크), Hover: `#1D4ED8`
- Text: `#111827`, Subtext: `#6B7280`
- Typography: 14/16/20/24 스케일, 숫자(주문번호) 가독성 위해 monospace 옵션 제공
- Button
  - Primary(관리자 저장/추가): filled
  - Secondary(취소/닫기): outline
  - Danger(삭제): red outline + confirm modal

## 1) 로그인 페이지 (/login)
### Page Structure
- 중앙 정렬 단일 카드(최대 420px), 브랜드/서비스명 상단.

### Sections & Components
- 입력 폼: 이메일, 비밀번호, 로그인 버튼
- 상태: 로딩 스피너, 에러 토스트(자격 증명 실패 등)

## 2) 주문 목록 페이지 (/orders)
### Page Structure
- 상단: 페이지 타이틀 + (옵션) 간단 필터 영역
- 본문: 주문 테이블(데스크톱) / 카드 리스트(모바일)

### Sections & Components
- 주문 리스트 테이블
  - 컬럼: 주문상세 번호(링크), 주문일, 상태
  - 상호작용: **주문상세 번호 클릭 → /orders/:orderId 이동**
- 빈 상태: 주문 없음 안내 문구

## 3) 주문 상세 페이지 (/orders/:orderId)
> 고객은 조회 전용, 관리자/제작자는 편집 UI가 추가 노출.

### Page Structure
- 상단 요약 영역(고정 폭 카드): 주문번호/상태/핵심 정보
- 하단 제작 단계 영역: 세로 타임라인(좌측 단계 인덱스/우측 콘텐츠 카드)

### Sections & Components
#### A. 주문 요약 카드
- 요소: 주문상세 번호(강조), 상태 배지, 생성일
- 액션: 뒤로가기(목록), (관리자) 상태 변경이 범위에 포함되지 않으면 표시하지 않음

#### B. 제작 단계 타임라인(공통: 조회)
- 단계 카드(반복)
  - 헤더: `Step {n}` + (관리자일 때만) 이동(↑↓) 버튼
  - 한줄 메모: 1줄 텍스트(길면 말줄임) + 펼치기(옵션)
  - 사진 갤러리
    - 데스크톱: 3열 그리드(썸네일) + 클릭 시 라이트박스
    - 모바일: 1열 + 좌우 스와이프(간단 캐러셀)
  - 메타: 마지막 업데이트 시간(서브 텍스트)

#### C. 제작 단계 관리(관리자 전용)
- 단계 추가
  - 위치: 타임라인 상단 또는 하단에 `+ 단계 추가` 버튼
  - 동작: 새 단계 생성 후 바로 편집 포커스
- 단계 편집
  - 한줄 메모 입력: 단일 라인 input(Enter 저장 또는 저장 버튼)
  - 저장/취소 버튼
- 단계 삭제
  - Danger 버튼 + 확인 모달(“이 단계와 사진이 삭제됩니다”)

#### D. 단계 사진 관리(관리자 전용)
- 업로더
  - Drag & Drop 영역 + 파일 선택 버튼
  - 업로드 진행률 표시(퍼센트)
- 사진 정렬
  - 썸네일 그리드에서 드래그 정렬(또는 ↑↓)
  - 저장 시 `sort_order` 업데이트
- 사진 삭제
  - 썸네일 우상단 휴지통 아이콘 + 확인

### Interaction States
- 권한 분기
  - 고객: 추가/수정/삭제/업로드/정렬 컨트롤 숨김
  - 관리자: 모든 컨트롤 표시
- 에러
  - 업로드 실패: 재시도 버튼 + 실패 항목만 유지
  - 저장 충돌(동시 편집): “최신 데이터로 새로고침” 안내
